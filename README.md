# H2C_launch_DCV

Two scripts to launch a NICE DCV session (https://www.ni-sp.com/products/nice-dcv/) on the Hoffman2 Cluster (https://www.hoffman2.idre.ucla.edu/). 

## h2c_launch_dcv.sh for MacOS, Linux and Windows w/ WSL and/or GitBash

```
bash h2c_launch_dcv.sh -u <your-hoffman2-cluster-username>
```

## h2c_launch_dcv.exe for Windows PowerShell

```
.\h2c_launch_dcv.cmd -u <your-hoffman2-cluster-username>
```
